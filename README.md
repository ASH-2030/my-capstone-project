# My Capstone Project

## Description

This is my AI-assisted development capstone project. It will demonstrate modern JavaScript development practices with AI pair programming.

## Tech Stack

- Node.js (LTS)
- JavaScript
- npm

## Prerequisites

- [Node.js](https://nodejs.org/) 20 LTS or later
- npm (included with Node.js)

Verify your setup:

```bash
node --version
npm --version
```

## Getting Started

1. Clone the repository and open a terminal in the project folder.
2. Install dependencies (there are none yet, but this confirms npm is configured correctly):

   ```bash
   npm install
   ```

3. Run the application:

   ```bash
   npm start
   ```

   This runs `node src/index.js`. The entry point is still a scaffold, so you may not see output yet.
